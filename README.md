## 💻 Featured Projects

### 1. TicketChain - Blockchain-Based Event Digital Ticket System

A full-stack digital ticketing application that issues event tickets as NFTs and supports ticket transfers and ownership verification.

- **Technologies:** React.js, Solidity, Ethereum Sepolia Testnet, ERC-721, Privy.io, MetaMask, Firebase Firestore, IPFS, Vercel.
- **Highlights:** Developed and deployed ERC-721 smart contracts, integrated wallet connections and transaction signing, managed event and user data in Firestore, and stored ticket metadata and assets on IPFS.
- **Focus:** Smart contract development, NFT ticketing, and end-to-end blockchain integration testing.

### 2. Ocular Infection Detection System - Eye Disease Classification

A deep learning image classification project using retinal fundus images to distinguish **Cataract, Diabetic Retinopathy, Glaucoma, and Normal** categories.

- **Technologies:** Python, TensorFlow, Keras, MobileNetV2, OpenCV, Matplotlib, Seaborn.
- **Highlights:** Applied transfer learning to a dataset of **4,217 fundus images**, with preprocessing, image augmentation, and early stopping.
- **Result:** Achieved approximately **82% validation accuracy** during training across 20 epochs.
- **Focus:** Computer vision, CNNs, model evaluation, and prediction visualization.

### 3. Kedai Ibunon - Online Food Ordering System

A responsive online food ordering system developed for a client as my diploma final-year project.

- **Technologies:** HTML, CSS, JavaScript, PHP, MySQL.
- **Highlights:** Built responsive interfaces, collaborated on user-friendly designs, optimized performance through coding and caching techniques, and tested and debugged the application.
- **Focus:** Full-stack web development, usability, and performance optimization.

### 4. Car Loan System

A C# visual programming project with interfaces for a car loan system and a data access layer for storing and retrieving information.

- **Technologies:** C#.
- **Highlights:** Designed forms and interface controls, implemented data access, and tested the application using different inputs and scenarios.
- **Focus:** Visual programming, interface design, data handling, and debugging.

### 5. Sales Report Graphs

A data visualization project presenting sales team performance over a six-month period.

- **Technologies:** Python, Matplotlib, Seaborn, HubSpot.
- **Highlights:** Exported sales data from HubSpot and created graphs tailored to reporting requirements, with clear titles, legends, and colors.
- **Focus:** Data visualization, analytics, and business reporting.
