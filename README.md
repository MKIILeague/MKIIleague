## Selected projects

### 01 · Eye Disease Classification

**Deep Learning · Computer Vision · Transfer Learning**

An image classification project that uses retinal fundus images to distinguish **Cataract, Diabetic Retinopathy, Glaucoma, and Normal** categories.

I applied transfer learning with **MobileNetV2** to a dataset of **4,217 images**, using preprocessing and augmentation to prepare the data. Training included early stopping, with approximately **82% validation accuracy** across 20 epochs. I also visualized training curves and predictions to understand the model's performance.

`Python` `TensorFlow` `Keras` `MobileNetV2` `OpenCV` `Matplotlib` `Seaborn`

### 02 · Kedai Ibunon

**Full-Stack Development · Online Food Ordering**

A responsive food ordering application developed for a client as my diploma final-year project.

I worked on responsive interfaces, database-backed functionality, performance improvements, and testing, bringing together the front-end and back-end pieces of a practical web application.

`HTML` `CSS` `JavaScript` `PHP` `MySQL`

### 03 · TicketChain

**Full-Stack Application · Digital Event Ticketing**

A digital ticketing application supporting ticket issuance, transfers, and ownership verification.

I built the React interface, integrated wallet connections and transaction signing, and used Firestore for event and user data. The project also involved Solidity contracts and IPFS storage, giving me experience connecting a front end with several services.

`React` `Solidity` `Firebase Firestore` `IPFS` `MetaMask` `Privy` `Vercel`

### 04 · Sales Data Visualization

**Python · Analytics · Reporting**

A visualization project presenting sales team performance over six months.

I worked with data exported from HubSpot and built graphs using Matplotlib and Seaborn, choosing chart formats, titles, legends, and colors to make the results easier to interpret.

`Python` `Matplotlib` `Seaborn` `HubSpot`
